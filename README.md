# Dymola Parallel Runner — 배포

Dymola 배치 해석을 동시 실행 수 안에서 병렬로 돌리고 진행을 한 창에서 보는 Windows 프로그램의 **설치 파일 배포용 저장소**입니다.
소스 코드는 이 저장소에 없습니다.

- **최신 설치 파일: [DymolaParallelRunner_Setup_x64.exe](https://github.com/JunghunYun96/DymolaParallelRunner-releases/releases/latest/download/DymolaParallelRunner_Setup_x64.exe)**
- 버전별 설치 파일 · 설치 없이 쓰는 zip · 체크섬 (`SHA256SUMS.txt`): [Releases](https://github.com/JunghunYun96/DymolaParallelRunner-releases/releases)
- 이미 설치되어 있으면 새 설치 파일을 실행하기만 하면 업데이트됩니다. 1.7.0 부터는 프로그램이 시작할 때 새 버전을 확인하고 업데이트할지 묻습니다.
